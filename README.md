# Лабораторная работа №1. Первичное исследование и оценка качества данных

Курс «Введение в интеллектуальный анализ данных».

Первичный анализ датасета клиентов интернет-магазина `online_store_customers.csv` (1003 строки, 11 признаков): паспорт датасета, аудит качества (пропуски, дубликаты, невозможные значения, «грязные» категории, выбросы), мини-EDA и отчёт с планом улучшения качества.

## Структура репозитория

```
.
├── README.md
├── .gitignore
├── data/
│   └── online_store_customers.csv       # исходный датасет
├── notebooks/

└── report/
    └── quality_report.md                # отчёт о качестве данных
```

## Как запустить

1. Установите Python 3.10+ и зависимости:

   ```bash
   pip install pandas numpy matplotlib seaborn scipy jupyter
   ```

2. Запустите Jupyter из корня репозитория и откройте ноутбук:

   ```bash
   jupyter notebook notebooks/01_data_understanding.ipynb
   ```

3. Выберите *Kernel → Restart & Run All*. Ноутбук читает данные по относительному пути `../data/online_store_customers.csv`, ручные правки не нужны.

## Основные результаты

Найдено 9 проблем качества: пропуски в 4 признаках, 3 дубликата, 3 невозможных значения возраста, «грязные» названия городов и способов оплаты, экстремальные значения `total_spent` и `average_check`, значения-заглушки на границах и нарушения связи `total_spent ≈ orders_count × average_check`. Подробности и план улучшения — в [`report/quality_report.md`](report/quality_report.md).
